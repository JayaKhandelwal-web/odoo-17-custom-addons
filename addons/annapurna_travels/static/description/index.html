📦 Installation Instructions

  1. Copy the annapurna_travels folder to your Odoo addons directory
  2. Restart your Odoo server
  3. Go to Apps menu and update the apps list
  4. Search for "Annapurna Travels" and click Install
  5. Configure your services, fleet, and packages
  6. Enable website features if needed
