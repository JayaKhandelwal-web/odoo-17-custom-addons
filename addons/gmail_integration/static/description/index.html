Gmail Integration

Complete Gmail Integration for Odoo v17.0+

Transform your Odoo experience with seamless Gmail integration. Send, receive, and manage emails directly within Odoo while maintaining the power and reliability of Gmail's infrastructure.

🛠 Technical Stack

Gmail API v1 Google Cloud Pub/Sub OAuth 2.0 Python 3.8+ Odoo 17.0+ PostgreSQL HTML/CSS/JS

📋 Requirements

  • Odoo Version: 17.0 or higher
  • Google Cloud Account: With Gmail API enabled
  • Python Libraries: google-auth, google-api-python-client, google-cloud-pubsub
  • Gmail Account: G Suite or regular Gmail account
  • Internet Connection: For API communication

🔧 Installation Steps

1. Install Module: Upload and install the gmail_integration module in Odoo
2. Google Cloud Setup: Create project, enable Gmail API, configure OAuth
3. Configure Account: Add Gmail account with OAuth credentials
4. Test Connection: Verify Gmail API connectivity
5. Setup Webhooks: Configure real-time sync (optional)
⚠️ Important Notes:
  • Gmail API has daily quota limits - monitor usage in the module
  • OAuth tokens need periodic refresh - automated by the module
  • Large mailboxes may take time for initial synchronization
  • Enable two-factor authentication on Gmail for enhanced security
